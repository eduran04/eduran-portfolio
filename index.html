Project 01 — 2026

MITRE eCTF 2026

Secure HSM firmware for the MSPM0L2228, developed with a team of four (Team Sunrise, UCCS). Stores and transfers IC fabrication files with group-based authorization and PIN protection under the eCTF adversarial harness; the competition toolchain uses Docker for reproducible builds and testing. Cryptography includes ChaCha20-Poly1305, PBKDF2-SHA256, HKDF-SHA256, and HMAC-SHA-256, as documented in our system design (attack model, UART command set, defense-in-depth).

Embedded Systems Cryptography C Docker Security

Digital Fingerprint Analysis Tool.
